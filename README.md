# Vu Thi Phuong Hang — Portfolio

A playful Y2K-inspired personal portfolio built with HTML, CSS, JavaScript and a Flask backend.

## Run locally

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Backend endpoints
- `/api/profile`
- `/api/health`

## Social links
Edit `templates/index.html` and replace the placeholder `href="#"` links for Instagram/Facebook and `your-email@example.com`.
